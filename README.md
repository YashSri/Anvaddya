# Anvaddya Orbit - Website

Public-facing programme website for **Anvaddya Orbit**, a school-embedded applied STEM and innovation programme by Anvaddya.

Built with Next.js 16 (App Router), React 19, Tailwind CSS 4 and TypeScript. All pages are pre-rendered as static HTML; the only server code is the enquiry endpoint, which sends email through [Resend](https://resend.com).

## Getting started

```bash
npm install
cp .env.example .env.local   # then fill in the values
npm run dev                  # http://localhost:3000
```

Production build:

```bash
npm run build
npm start
```

## Environment variables

| Variable | Required | Purpose |
|---|---|---|
| `RESEND_API_KEY` | Yes, for the form | Resend API key |
| `ENQUIRY_TO_EMAIL` | Yes, for the form | Inbox that receives enquiries (comma-separate for several) |
| `ENQUIRY_FROM_EMAIL` | Yes, for the form | Sender address, e.g. `Anvaddya Orbit <enquiries@anvaddya.com>` |
| `NEXT_PUBLIC_SITE_URL` | Recommended | Canonical site URL for metadata, sitemap and Open Graph |
| `NEXT_PUBLIC_GA_MEASUREMENT_ID` | Optional | Google Analytics 4 ID (`G-…`). Unset = no analytics and no cookie banner |

If any form variable is missing, `/api/enquiry` returns **503** and the form tells the visitor that online enquiries are unavailable, offering the email address instead. It never shows a fake success.

### Resend setup

1. Create an API key at <https://resend.com/api-keys> and put it in `.env.local` (never commit it).
2. **Before launch, verify the `anvaddya.com` domain** in Resend (Domains → Add domain → add the DNS records), then set `ENQUIRY_FROM_EMAIL` to an address on that domain.
3. Until the domain is verified, you can test with `onboarding@resend.dev` as the sender, but Resend only delivers test mail **to the email address that owns the Resend account**.
4. On your host (Vercel, Netlify, etc.), add the same variables in the project's environment settings.

Spam protection: a hidden honeypot field, a minimum fill time, and a best-effort per-IP rate limit (5 per 10 minutes per server instance). Replies to an enquiry email go straight to the person who submitted it (`replyTo`).

### Analytics and cookie consent

Analytics is off by default. Set `NEXT_PUBLIC_GA_MEASUREMENT_ID` to enable Google Analytics 4. A consent banner then appears; GA loads **only after** the visitor accepts, advertising signals stay denied, and withdrawing consent (footer → *Cookie preferences*) removes the `_ga` cookies. The integration lives in `src/lib/analytics.ts` and `src/components/Analytics.tsx`.

## Design

- Palette: orange and white, with deep burnt-orange (`night`) contrast sections. Tokens are in `src/app/globals.css`.
- Type: Instrument Serif (display) and Manrope (body), loaded through `next/font`.
- Motion: CSS-only scroll reveals and marquee, disabled under `prefers-reduced-motion`.

## Content guardrails

This is a public website. Do **not** add pricing, revenue, costs, margins, financial projections, target school names, invented testimonials, partner logos, statistics, accreditations or admission/career guarantees. Project examples are labelled *illustrative* until real, approved student work is available.

## Site structure

```
/                         Home
├── /programme            The Programme
├── /curriculum           Classes 1–12 Curriculum
├── /technology-and-domains
├── /how-we-learn
├── /student-outcomes
├── /stream-choice
├── /for-schools
├── /events
├── /faq
├── /contact              Partner With Us (enquiry form)
├── /privacy              Privacy Policy (incl. cookies, /privacy#cookies)
├── /terms                Terms of Use
└── (404)                 Custom not-found page
```

`/sitemap.xml`, `/robots.txt`, `/manifest.webmanifest`, `/favicon.ico`, `/icon.svg`, `/apple-icon`, `/opengraph-image` and `/twitter-image` are generated by Next.js. `/api/enquiry` is excluded from crawling.
